      How the sending works
      
  
      
  
      
    
      Pick skills in the web or the lists, then press Send to Claude. Your browser hands a request to Claude Code on your own machine, the desktop app or the terminal, with your list already typed in. Claude downloads each skill straight from its author’s GitHub, reads it before installing it, and puts it in ~/.claude/skills, where every session after that can use it.
      
    
      Nothing is sent until you press Enter, and nothing passes through this site: it only writes the request. Skills are other people’s code and instructions, so the request tells Claude to stop and tell you if a skill does something its description does not explain.
